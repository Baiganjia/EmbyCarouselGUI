# Emby 配置 GUI 轮播方案搭配说明
## 概述
> 白干PC客户端专用（Baigan Only）

`EmbyCarouselGUI` 脚本通过灵活的配置选项，支持生成多样化的 Emby 轮播方案。用户可以根据媒体类型、媒体库、排序规则、优先展示影片及其他筛选条件，创建适用于不同场景的轮播内容，例如每日推荐、近期上映、新剧集推荐或随机合集等。本节集中介绍脚本支持的轮播方案搭配，帮助用户快速了解如何配置并生成符合需求的轮播数据。

**开发初衷**：
纯粹随机抽卡的轮播真的有意义吗？许多播放器或轮播方案只是简单地随机抽取媒体库中的内容，但这样的展示未必能吸引用户点击。首页作为首页，在最显眼、最顶端的位置，需要精心管理和展示，而 Emby 无法自动提供足够智能的推荐逻辑——这往往是影视网站编辑的工作。那么，能否有一个工具，在保留轮播随机性的基础上，允许用户手动添加限制条件，打造更个性化的轮播体验？`EmbyCarouselGUI` 正是为此而生。它通过直观的 GUI 界面，让用户能够灵活定制轮播规则，既保留随机探索的乐趣，又能突出个人偏好或热门内容，确保首页轮播真正“言之有物”。我不会编程，不是相关从业者，我知道这个方案很不优雅，因为需要手动，如果有人能把这个方案做成插件，感激不尽。



## 主要功能
该脚本提供以下核心功能：

1. **服务器配置**：
   * 支持输入和保存 Emby 服务器地址（如 `http://127.0.0.1:8096`）和 API 密钥。
2. **选项卡管理**：
   * 使用选项卡组织配置，包括固定的“配置录入”选项卡、“每日电影”选项卡及用户自定义的动态选项卡。
   * 支持最多 10 个动态选项卡，可添加、重命名或删除。
   * 每个选项卡可独立配置媒体抽取规则，如媒体类型、排序方式和保留数量。
3. **媒体抽取规则**：
   * 支持选择媒体类型（电影、剧集、合集）及具体媒体库（比如不抽小姐姐库，他真的太懂我）。
   * 提供灵活的筛选选项，包括：
      * 排序方式（如随机、首映日期、评分）。
      * 是否包含子目录（递归搜索）。
      * 最小首映日期（如最近 45 天的影片）。
      * 优先展示的影片（支持中英文逗号分隔）。
   * 可设置每个媒体库的搜索数量及最终保留数量。
4. **轮播数据生成**：
   * 生成 `data_pc.js` 文件，包含 JSON 格式的轮播数据，可用于 `白干PC客户端`首页展示。
   * 包含媒体元数据，如标题、简介、图片链接（背景、封面、Logo）及自定义提示。
   * 支持多种过渡效果（如缩放、淡入淡出）和样式配置。
5. **配置持久化**：
   * 将所有配置保存至 `config.json` 文件，包括服务器信息和选项卡设置。
   * 支持加载已有配置，快速恢复之前的设置。
6. **用户友好界面**：
   * 提供清晰的选项卡布局，包含输入框、下拉菜单、复选框和按钮。
   * 通过文本区域实时显示轮播生成结果及输入解析信息（如优先展示的影片列表）。
   * 包含错误处理，针对无效输入或服务器错误弹出提示。
7. **扩展性**：
   * 支持通过名称或 ItemId 添加自定义媒体库。
   * 提供模板（如“近期上映”、“随机合集”）快速创建选项卡。

## 使用指南
1. **启动程序**：
   * 运行 `python EmbyCarousel_GUI.py`，打开 GUI 界面。
2. **配置服务器**：
   * 在“配置录入”选项卡中输入 Emby 服务器地址和 API 密钥。
   * 点击“保存配置”或“载入配置”以保存或恢复设置。
3. **管理选项卡**：
   * 使用“每日电影”选项卡配置默认推荐，或通过“+”选项卡添加自定义选项卡。
   * 双击选项卡名称可重命名，点击“删除”按钮移除动态选项卡。
   * 拖动选项卡调整顺序。
4. **设置抽取规则**：
   * 在每个选项卡中选择媒体类型（电影、剧集、合集）、媒体库及排序规则。
   * 输入优先展示的影片名称（支持中英文逗号分隔，如 `电影1,电影2` 或 `电影1，电影2`）。
   * 设置保留数量、首映日期等筛选条件。
5. **生成轮播**：
   * 点击“生成轮播”按钮，生成 `data_pc.js` 文件。
   * 查看界面底部的文本区域，确认生成的媒体信息。
6. **保存与加载**：
   * 点击“保存配置”将设置保存至 `config.json`。
   * 点击“载入配置”恢复之前的设置。
7. **定期生成**：
   * 添加计划任务，自动定期运行 `python EmbyCarousel_NoGUI.py` 
   * 会自动按照配置规则，静默化生成轮播数据，每次打开Emby都能看到最新首页



## 轮播方案配置选项
脚本提供以下关键配置选项，组合这些选项可生成多样化的轮播方案：

1. **媒体类型**：
   * 电影（Movie）：适用于单部影片推荐。
   * 剧集（Series）：适用于电视剧或连续剧集。
   * 合集（BoxSet）：适用于影片合集或系列电影。
   * 示例：选择“电影”生成新片推荐，选择“剧集”生成热门电视剧轮播。
2. **媒体库选择**：
   * 支持从 Emby 服务器的电影、剧集或合集媒体库中选择一个或多个。
   * 可添加自定义媒体库（通过名称或 ItemId）。
   * 示例：选择“动作电影”库生成动作片轮播，或选择多个库混合推荐。
3. **排序规则**：
   * 随机（Random）：随机挑选媒体，适合多样化推荐。
   * 首映日期（PremiereDate）：按上映时间排序，适合新片推荐。
   * 制作年份（ProductionYear）：按年份排序，适合经典影片。
   * 名称（SortName）、社区评级（CommunityRating）、评论家评级（CriticRating）等。
   * 排序方式：正序（Ascending）或倒序（Descending）。
   * 示例：按“首映日期”倒序生成最新影片轮播，按“社区评级”正序生成高分影片轮播。
4. **优先展示**：
   * 支持输入特定影片名称（英文逗号分隔，如 `电影1,电影2` ），优先包含在轮播中。
   * 示例：输入 `阿凡达,星际穿越` 确保这些影片优先显示。
5. **筛选条件**：
   * 是否包含子目录（递归搜索）：适合搜索整个媒体库或仅顶层内容。
   * 最小首映日期：限制影片上映时间（如最近 45 天）。
   * 每个媒体库搜索数量（1-10）：控制每个库的候选影片数量。
   * 结果保留数量（1 或更多）：控制最终轮播的影片数量。
   * 示例：设置“最近 30 天”生成近期上映影片轮播，设置“保留 1 部”生成每日单片推荐。
6. **模板支持**：
   * 提供预设模板，快速配置常见轮播方案：
      * 默认：随机电影推荐。
      * 近期上映：最新电影，按首映日期倒序。
      * 近期剧集：最新剧集，按首映日期倒序。
      * 随机合集：随机挑选合集。
      * 电影、剧集、合集：分别针对特定媒体类型优化。
   * 示例：选择“近期上映”模板自动配置新片推荐规则。

## 典型轮播方案搭配
以下是基于上述配置选项的典型轮播方案搭配，展示脚本的灵活性：

### 1\. 每日电影推荐
* **场景**：每天推荐一部随机电影，增加用户探索的趣味性。
* **配置**：
   * 媒体类型：电影
   * 媒体库：所有电影库（或指定某库，如“热门电影”）
   * 排序规则：随机
   * 筛选条件：
      * 包含子目录：是
      * 每个库搜索数量：1
      * 结果保留数量：1
   * 优先展示：无（或指定特定影片，如 `流浪地球`）
   * 模板：默认
* **效果**：生成包含一部随机电影的轮播，适合 Emby 首页的“每日推荐”板块。

### 2\. 近期上映影片
* **场景**：展示最近上映的电影，吸引用户关注新片。
* **配置**：
   * 媒体类型：电影
   * 媒体库：电影库（可多选）
   * 排序规则：首映日期，倒序
   * 筛选条件：
      * 包含子目录：是
      * 最小首映日期：最近 45 天
      * 每个库搜索数量：2
      * 结果保留数量：3
   * 优先展示：无（或指定新片，如 `沙丘2，奥本海默`）
   * 模板：近期上映
* **效果**：生成包含 3 部最新电影的轮播，优先展示指定影片，适合“新片速递”板块。

### 3\. 最近入库剧集
* **场景**：推荐近期入库更新电视剧。
* **配置**：
   * 媒体类型：剧集
   * 媒体库：勾选剧集库（如“美剧”或“国产剧”）
   * 排序规则：首映日期，倒序（或社区评级，正序）
   * 筛选条件：
      * 包含子目录：否（仅推荐剧集根目录）
      * 最小首映日期：最近 60 天
      * 每个库搜索数量：2
      * 结果保留数量：4
   * 优先展示：如 `权力的游戏，漫游记`（热门剧集名称）
   * 模板：近期剧集
* **效果**：生成包含 4 部热门或新剧的轮播，适合“热播剧集”板块。

### 4\. 经典合集精选
* **场景**：随机展示经典电影合集，如漫威系列或星球大战系列。
* **配置**：
   * 媒体类型：合集
   * 媒体库：合集库（如“系列电影”）
   * 排序规则：随机
   * 筛选条件：
      * 包含子目录：否
      * 每个库搜索数量：1
      * 结果保留数量：2
   * 优先展示：如 `复仇者联盟`（指定合集名称）
   * 模板：随机合集
* **效果**：生成包含 2 个随机合集的轮播，优先展示指定合集，适合“系列电影”板块。

### 5\. 高分电影推荐
* **场景**：推荐社区评分高的电影，提升用户观看质量。
* **配置**：
   * 媒体类型：电影
   * 媒体库：所有电影库
   * 排序规则：社区评级，正序
   * 筛选条件：
      * 包含子目录：是
      * 每个库搜索数量：3
      * 结果保留数量：5
   * 优先展示：无
   * 模板：电影
* **效果**：生成包含 5 部高分电影的轮播，适合“高分推荐”板块。

### 6\. 自定义主题轮播
* **场景**：为特定主题（如科幻、爱情）创建轮播，结合自定义媒体库，特别适合实时展示热门内容。
* **配置**：
   * 媒体类型：电影或剧集
   * 媒体库：通过 [EMBY\_HotMovie\_Importer\_V2](https://github.com/Baiganjia/EMBY_HotMovie_Importer_V2/) 创建的自定义合集，如“热门电影”或“热门剧集”（通过 ItemId 添加）。
      * **热门剧集合集**：类似地，导入热门剧集（如近期热播的国产剧或美剧），生成合集。
   * 排序规则：随机（或按导入时间倒序，突出最新热门内容）
   * 筛选条件：
      * 包含子目录：是（若合集包含子目录）
      * 每个库搜索数量：2
      * 结果保留数量：3
   * 优先展示：如 `最后生还者`（结合热门合集中的具体影片）
   * 模板：默认或电影/剧集
* **效果**：
   * 生成包含 3 部热门电影或剧集的轮播，基于 EMBY\_HotMovie\_Importer\_V2 实时更新的合集，确保内容紧跟热度。
   * 例如，展示如《最后生还者》和《无痛凯恩》。适合 Emby 首页的“实时热门”板块，吸引用户关注当前最受欢迎的影剧。
* **实现步骤**：
   1. 在脚本的选项卡中，通过“添加自定义抽取源”输入合集名（如 热门电影），添加“热门电影”或“热门剧集”合集。
   2. 配置其他规则（如随机排序、保留 3 部），点击“生成轮播”。

## 配置灵活性
通过组合上述选项，用户可以创建几乎无限的轮播方案。例如：

* **混合媒体类型**：在同一选项卡中选择电影和合集，生成混合轮播。
* **多库组合**：从多个媒体库抽取内容，生成多样化推荐。
* **动态调整**：通过调整保留数量或首映日期，控制轮播内容的更新频率（如每日、每周）。
* **优先级控制**：利用优先展示功能，确保特定影片始终出现在轮播中。
* **实时热门**：结合 EMBY\_HotMovie\_Importer\_V2 的动态合集，生成实时更新的热门影剧轮播。

## 使用提示
* **优先展示**：输入影片名称时，可使用英文逗号分隔（`电影1,电影2`），脚本会自动解析。
* **模板选择**：使用模板可快速配置常见方案，减少手动设置时间。
* **多选项卡**：创建多个选项卡（如“新片”和“热门”），分别生成不同轮播组合，满足多样化需求。
* **验证配置**：生成轮播后，检查界面底部的文本区域，确认优先展示影片和总数是否符合预期。
* **定期执行**：定期运行NOGUI版本，可以按照保存的规则自动更新合集轮播数据，确保每次打开Emby都是最新热门影剧。
